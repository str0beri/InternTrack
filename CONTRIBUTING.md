# Contributing to InternTrack

Thank you for your interest in contributing to InternTrack!

InternTrack is an On-the-Job Training (OJT) management system designed to help students, company supervisors, and OJT coordinators manage internship activities.

## Ways to Contribute

You can contribute by:

- Reporting bugs and technical issues.
- Suggesting new features or improvements.
- Improving the user interface and user experience.
- Updating project documentation.
- Fixing existing issues.

## Reporting Issues

Before reporting an issue:

1. Check the existing GitHub Issues to avoid duplicates.
2. Create a new issue with a clear and descriptive title.
3. Explain the problem or suggestion.
4. Include steps to reproduce the issue, if applicable.
5. Attach screenshots or error messages when helpful.

## Development Workflow

1. Fork the repository or create a new branch if you have write access.
2. Create a descriptive branch name.
3. Make your changes.
4. Test your changes before submitting.
5. Commit your changes with a meaningful message.
6. Push your branch to GitHub.
7. Open a pull request targeting the `main` branch.

## Commit Message Guidelines

Use clear and descriptive commit messages.

Examples:

- `feat: add attendance summary`
- `fix: resolve login validation issue`
- `docs: update installation guide`
- `style: improve dashboard layout`
- `refactor: simplify attendance logic`

## Pull Request Guidelines

When submitting a pull request:

1. Provide a clear title.
2. Describe the changes made.
3. Explain why the changes are necessary.
4. Include screenshots for UI-related changes when applicable.
5. Make sure the application still works as expected.
6. Link related GitHub Issues when applicable.

## Code Quality

- Follow the existing project structure.
- Use meaningful variable and function names.
- Keep code readable and organized.
- Avoid committing passwords, API secrets, or private credentials.
- Test affected features before submitting changes.

## Community Guidelines

Be respectful and constructive when discussing issues, suggesting improvements, or reviewing contributions.

## Project Maintenance

Contributions may be reviewed before being merged to ensure they align with InternTrack's goals and requirements.

Thank you for helping improve InternTrack!
